Add issue intake (ADR-0007). A new `sentinel-intake` skill interviews you about what is missing from a feature or bug, plans attachments, lints the draft, checks for duplicates, proposes a priority and stops for your approval before it files or refines the issue in the standard issue format. New CLI commands: `sentinel issue template <feature|bug>`, `sentinel issue lint <file> --kind <kind>` (exit 0 to file, 2 to fix; checks sections, `AC-n` Given/When/Then, placeholders, vague wording and secrets), `sentinel issue attachments <files…> [--tracker-uploads]` (inline, attach, pending upload, blocked or rejected per file), and, for the local tracker, `sentinel issue update` and `sentinel issue attach`. `sentinel setup --issue-forms` writes GitHub issue forms in the same format. `issue describe` lists the new neutral verbs `update` and `attach`. `sentinel-prd` now maps issue sections onto the PRD, and `sentinel-setup` offers the issue forms when the tracker is GitHub.
