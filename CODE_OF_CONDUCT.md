# Code of conduct

We want sentinel to be a welcoming project for everyone who contributes, files an issue or asks a
question.

## Our standard

- Be respectful and assume good faith. Disagree with ideas, not with people.
- Give and accept feedback on code and design constructively.
- Keep discussions on topic, and make room for newcomers.
- No harassment, discrimination, personal attacks, or publishing someone's private information.

## Scope

This applies in the project's spaces: the repository, its issues, pull requests and discussions,
and any place where someone represents the project.

## Enforcement

Report unacceptable behaviour through
[a private security advisory](https://github.com/robert-nagy/sentinel/security/advisories/new)
marked as a conduct report, or by contacting the maintainer, Robert Nagy, through the contact
details on the GitHub profile. Reports are handled privately. Maintainers may remove comments, lock
discussions or block contributors who violate this code.

## Attribution

This code is modelled on the principles of the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
which applies as a more detailed reference where this document is silent.
